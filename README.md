# andreferraz20.github.io

Portfólio pessoal de **André Ferraz** — Desenvolvedor Backend (Node.js, TypeScript, NestJS).

🔗 Publicado em: https://andreferraz20.github.io/

## Stack da página

Página estática em HTML + CSS puro (sem build step), com tema claro/escuro automático via `prefers-color-scheme`.

## Rodar localmente

Basta abrir o `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
npx serve .
```

## Deploy

O deploy é automático via **GitHub Pages**, publicando o conteúdo da branch `main`.
