GET/sobre

Backend com foco em produção

Sou desenvolvedor backend com mais de 4 anos de experiência, a maior parte deles na Grupo UAU (UAUBox, Scarlet e Experimentaí), uma empresa de e-commerce e assinatura de beleza. Lá trabalhei com microsserviços no GCP, integrações de pagamento e arquitetura orientada a eventos.

Gosto de resolver problemas reais de produção: concorrência, consistência de dados entre serviços, falhas em pipelines. Acompanho as entregas até o deploy e investigo incidentes a partir de logs e métricas.

Também construo soluções com IA generativa: de um assistente conversacional com a API do Claude a agentes em TypeScript que apoiam o code review do time.
